One input where you paste a JD and get the twenty best-matching builders back, each with the evidence behind the match rather than a similarity percentage. It combines the embeddings and vector index that semantic search already uses with a new registry task and a validated structured output. Sprints already do something adjacent by running in the background; this is the impatient, synchronous version of the same question.

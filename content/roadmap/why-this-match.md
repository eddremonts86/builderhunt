An expandable panel on each result showing exactly which posts, commits and dates moved the score, each linking to the original. Every kind of user asks the same first question — is this a real person or noise — and today the answer is a number they have to trust. This makes the score auditable instead of authoritative, and it is a pure consumer of data we already store.

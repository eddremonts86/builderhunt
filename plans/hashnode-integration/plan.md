# Plan: Hashnode Integration

## Status: likely skip

Honorable mention with low ROI. DEV.to already covers the same "developers who write" audience. Adding Hashnode would be 2-3 days of engineering for marginal value.

## When to reconsider

- If users explicitly request "find Hashnode writers"
- If DEV.to becomes unreliable or rate-limits us
- If we want a "more professional" version of the writing-focused source

## Better use of engineering time

If we have 2-3 days, the better candidates are:
1. **Lobsters** — unique high-signal community
2. **Stack Overflow** — expertise signal
3. **Hugging Face** — AI/ML niche

## Decision: skip for v1, conditional on user demand
